# Booking Labs

공간 예약과 회원 관리를 위한 소프트웨어를 만듭니다.

## 지금 만드는 것

**vocal-booking-mvp** — 보컬 학원 연습실 예약 / 수강생 관리 웹앱

- 수강생: 연습실 선착순 예약, 예약 임박 알림, 개인 연습 통계
- 원장: 이용 현황 대시보드, 수강생 문자 온보딩, 공간·휴무일·공지 관리

## 왜 만드는가

학원 원장은 구글 폼과 장부로 예약을 취합합니다.
수강생은 예약할 때마다 이름을 다시 적고, 예약한 날을 잊습니다.
노쇼가 생기면 다른 수강생의 기회가 사라집니다.

## 어디까지 갈 것인가

보컬 학원에서 시작해 같은 문제를 가진 곳으로 넓힙니다.
댄스·연기 아카데미, 실내 골프 스튜디오, 아파트 커뮤니티 센터.

## 일하는 방식

- 모든 설계 결정은 사람이 내립니다. AI는 초안과 비교 도구로만 씁니다.
- 동작은 [OpenSpec](https://github.com/Fission-AI/OpenSpec) 스펙으로 확정하고, 승인된 것만 main에 들어갑니다.
- main에는 PR로만 머지합니다.
